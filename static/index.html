    How it works

    Workplace injuries often come down to two things going unnoticed in time: someone without the right protective gear, or the first sign of smoke and fire. This system watches a work site's camera feed, checks it continuously, and raises an alert the moment either one shows up.

    1. 1 📹 The camera watches the work area, live or from a recording.
    2. 2 🧠 The AI model checks each frame for missing protective gear and for smoke or fire.
    3. 3 🚨 A match raises an alert with its zone and the type of issue, so the right person can act.

      1. At developers.facebook.com/apps, create an app with the Connect with customers through WhatsApp use case, then open API Setup
      2. Copy the Phone number ID shown under the “From” number (the ID, not the phone number itself)

      4. Make a permanent token: Business Settings → System users → Add, assign your app and WhatsApp account with full control, then Generate token with business_management, whatsapp_business_management and whatsapp_business_messaging. The temporary token on API Setup expires in 24 hours
      5. Enter the token, the ID and the recipient number(s) above (country code first, digits only, commas between numbers), then Save and Send test message
      6. For round-the-clock alerts: free text only works within 24 hours of the recipient’s last message. In WhatsApp Manager → Message templates, create a Utility template with four variables: {{1}} alert, {{2}} zone, {{3}} details, {{4}} time. Once approved, enter its name and language code above
